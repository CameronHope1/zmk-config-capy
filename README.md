# Capy Firmware

Firmware configuration for Capy, a custom handwired wireless split mechanical keyboard inspired by the Corne layout.

# Hardware
* Controllers: 2 × nRF52840-based nice!nano-compatible controllers
* Firmware: ZMK Firmware
* Layout: Split ortholinear (Corne-based)
* Matrix: 6 columns × 4 rows + 3-thumb cluster

# Building
Firmware is built automatically using GitHub Actions whenever changes are pushed to this repository.
To build locally, follow the official ZMK setup guide.

# Flashing
1. Put each controller into bootloader mode using reset buttons.
2. Download the firmware artifacts generated by GitHub Actions.
3. Copy the appropriate UF2 file to each controller's USB mass storage device.
4. Repeat for both the left and right halves.

# Bootloader
Enter the bootloader by briefly pressing the reset button twice (or following the procedure for your controller).

# Project and Build

This repository contains only the ZMK configuration and build workflow.
